# Portfólio Pessoal - João Pedro

Este é o meu portfólio pessoal, desenvolvido durante a minha formação no curso **Técnico em Desenvolvimento de Sistemas**. O objetivo deste projeto é apresentar meus trabalhos, competências técnicas e servir como um canal de contato profissional.

## 🚀 Tecnologias Utilizadas

O projeto foi estruturado com foco em boas práticas de Front-End:

* **HTML5**: Semântica e estrutura de conteúdo.
* **CSS3**: Layout responsivo com Flexbox, Grid e variáveis CSS.
* **JavaScript (ES6+)**: Interatividade, manipulação de DOM e persistência local.

## 🛠 Funcionalidades Principais

* **Design Responsivo**: Adaptado para diferentes resoluções de tela.
* **Navegação Intuitiva**: Implementação de *scroll-behavior* suave entre seções.
* **Formulário de Contato**: Sistema funcional que captura dados e os armazena localmente (`LocalStorage`) para fins de simulação e portfólio.
* **Identidade Visual**: Tema dark mode focado em alta legibilidade e contraste.
